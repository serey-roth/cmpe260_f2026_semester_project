Timing interpretation
---------------------
The full pytest process took 6.69 seconds. This includes Python startup,
pytest collection, importing the WebShop, Torch, Pyserini, and spaCy-related
modules, test execution, and test reporting.

The individual test durations in the JUnit XML report are rounded to a very
small value by pytest. Most individual tests are reported as 0.000 seconds,
and two are reported as 0.001 seconds. These values should not be interpreted
as exact timings. They indicate that the tests themselves are very fast and
that most of the measured runtime comes from process startup and imports.

Performance conclusion
----------------------
This is a fast offline evaluation suite:

  - Suitable for running during development or before each commit.
  - Does not start an Ollama model or execute a full shopping episode.
  - Does not measure model inference latency.
  - The current baseline is approximately 6.7 seconds per fresh test process
    on the machine used for this run.

Comparison with end-to-end runs
--------------------------------
These tests are not representative of the runtime of the Ollama-backed
baseline agent. The baseline agent can take approximately 1-5 minutes for a
complete episode because it may make up to 15 model requests. A first Ollama
run can take an additional 10-60 seconds while the model loads.
